**The Inbox's unread count can be shown on plMail's icon in the browser tab.** Switch on
**Settings → Notifications → Unread count on the browser tab icon** and the number of unread
conversations in the Inbox, the same number as the tab title, is drawn in the bottom right corner
of the tab icon, black with a thin white outline, so a pinned tab shows it too, as in Gmail. It
keeps up while the tab is in the background, and the "(3)" in the tab title now does as well for
anybody with the switch on. Off by default. No schema change.
[#662](https://github.com/karatektus/pl_mail/issues/662), requested by @llaumgui.
