**With "Folders in Labels" on, "Label as" offers an IMAP account's folders too, and keeps the mail
where it is.** Labelling a message with a folder copies it into that folder on the server, so it is
in both, the way a label works; taking the label off deletes that copy and leaves the others.
"Move to" still moves. Only for plain IMAP accounts: Gmail and JMAP already keep labels as labels,
and an Outlook folder is still a move. [#693](https://github.com/karatektus/pl_mail/issues/693).
