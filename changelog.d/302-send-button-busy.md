**The Send button no longer cancels the mail you just sent.** With the default "close it" send
behaviour, the button read *Sending… click to cancel* until the server answered, so a double click
called the send off. It is now a plain busy button; the toast's **Undo** is the way back. "Keep it
open" is unchanged: there the button is still the cancel. No schema change.
[#302](https://github.com/karatektus/pl_mail/issues/302), reported by @pmdevelopment.
